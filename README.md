# 今日のワークシート — 設置手順

所要15分。順番どおりにやれば動きます。

## 1. 保存先をつくる（GAS・5分）

1. Googleスプレッドシートを新規作成する（名前は「0915ワークシート」など）
2. 上部メニュー **拡張機能 → Apps Script**
3. 出てきたコードを全部消して、`Code.gs` の中身を貼り付ける
4. 右上 **デプロイ → 新しいデプロイ**
5. 歯車アイコン → **ウェブアプリ** を選ぶ
6. 「次のユーザーとして実行」＝**自分**、「アクセスできるユーザー」＝**全員**
7. **デプロイ** → 初回は承認画面が出る。「詳細」→「（プロジェクト名）に移動」→「許可」
8. 表示される `https://script.google.com/macros/s/..../exec` をコピー

> コードを直したときは、**デプロイ → デプロイを管理 → 鉛筆マーク → バージョン「新規」→ デプロイ**。
> 「新しいデプロイ」でやり直すとURLが変わるので注意。

## 2. URLを貼る

`config.js` の1行を書き換えるだけ。

```js
window.API_URL = "https://script.google.com/macros/s/..../exec";
```

## 3. GitHub Pagesに上げる

リポジトリに `index.html` `prompts.html` `wall.html` `style.css` `app.js` `icons.js` `nav.js` `config.js` を置き、
Settings → Pages → Branch: main / root → Save。

## 4. QRを3枚つくる

| 使う場面 | URL |
|---|---|
| 冒頭 | `https://（公開URL）/#/1` |
| 最後 | `https://（公開URL）/#/2` |
| ペアワーク | `https://（公開URL）/#/3` |
| プロンプト集（スライドp4のQR） | `https://（公開URL）/prompts.html` |

投影用（講師PCで開く）:

| 画面 | URL |
|---|---|
| 冒頭の集計 | `https://（公開URL）/wall.html?s=1` |
| 宣言の壁 | `https://（公開URL）/wall.html?s=2` |
| コピーの壁 | `https://（公開URL）/wall.html?s=3` |

壁は5秒ごとに自動更新。開いたままスライドと切り替えて使えます。

## 5. 本番前に中身を消す

テスト投稿を消すには、ブラウザで次を開く（`s1` は `s2` `s3` に変えられます）。

```
https://script.google.com/macros/s/..../exec?action=clear&screen=s1&pin=（自分で決めた文字列）
```

合言葉は `Code.gs` の1行目 `CLEAR_PIN` で決めます。公開リポジトリに置くときは、必ず初期値から変えてください。

## 当日、うまくいかないとき

- **通信が届かない**：参加者の画面は自動で「自分の画面だけ」モードになり、結果は普通に出ます。壁だけあきらめれば進行は止まりません
- **壁に何も出ない**：`config.js` のURLが空か、デプロイの「アクセスできるユーザー」が全員になっていない可能性が高いです
- **やり直したい**：結果の下の「やり直す」で最初から入力できます

## 入力内容について

本名・住所・電話番号は入力しない旨を各画面の冒頭に出しています。
画面2（宣言）では、参加者が「前のスクリーンに出す／出さない」を自分で選べます。画面3（贈るコピー）はニックネームのみ扱うため、常に壁に出ます。
外した場合、壁にはニックネームと見出しだけが出て、本文は出ません。
